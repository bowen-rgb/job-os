# JOB//OS 桌面版 · Agent 使用说明

适用于 Windows 桌面版 0.3.0。首次使用时，从教程进入「连接 agent」。已跳过教程的用户可以在「连接」页面继续配置。

## 连接和验证

选择本机 DeepSeek Harness 支持的提供方和模型。如需指定安装位置，请填写自己的 DSH 路径。凭据只在本机配置界面填写。保存后点击检测，查看实际返回的状态。能找到程序只代表已安装，成功收到模型响应才说明连接可用。缺少程序、模型配置或凭据时，请按界面提示修正并重试，也可以跳过并使用岗位库和材料管理。

## 开始一次申请

1. 读取当前候选人的档案、地区和时间要求。从原始招聘页核实职位编号、资格和申请入口。
2. 按职位编号、网址和已有申请记录去重。遇到结果不明的历史尝试，先查确认页面或邮件。
3. 从已确认的经历中选取相关项目和简历版本。缺失的个人声明保留为待确认项。
4. 先预填，核对岗位、附件和收件方。用户要求只起草时，保持草稿状态。
5. 获得对应授权后再执行提交或发送。分别记录发送凭据、招聘方回执和后续回复，保留时间与职位关联。

## 数据边界

候选人的简历、个人回答、目标单位、会话和申请记录属于其私人档案。通用模板使用占位符。公开仓库、日志样例和问题报告中请移除个人信息及凭据。
