# JOB//OS

JOB//OS 是一个本地运行的 Windows 求职工作台。你可以把职位、简历版本、申请进度和回执放在一起管理，随时查到某个岗位用了哪份材料，以及下一步需要做什么。

## 从这里开始

**Windows 桌面版 0.3.0** 已完成本地安装验证。公开发行后，在本仓库的 [Releases](../../releases) 下载 `JOB-OS-Setup-0.3.0.exe`，双击安装。发行页会同时提供 SHA-256 校验文件。

首次启动时选择「开始教程」，按引导建立自己的工作区。已有使用经验可以跳过，勾选「不再提示」会记住你的选择。

1. **准备档案。** 填写自己的求职方向、地区和可入职时间，导入简历。
2. **添加岗位。** 保存招聘入口，检查申请条件，选择要用于该岗位的简历版本。
3. **选择执行方式。** 可以手动推进，也可以在引导里配置 DeepSeek Harness，保存后测试连接。暂时没有可用凭据时可以先离线使用。
4. **跟进结果。** 提交后记录确认页面或邮件回执。需要补资料、等待人工确认和已收到回执的岗位可以分别跟进。

## 数据和授权

档案、材料和申请记录保存在本机。连接外部模型、招聘网站或邮箱时，对应服务会参与处理你选择的操作。发送申请前应核对岗位、收件方和附件。卸载桌面程序后会保留用户数据。

## 旧版用户

仓库原名为 **Job Apply Assistant**。在桌面版发布前，现有源码版本仍可通过 [用户指南](https://github.com/bowen-rgb/job-apply-assistant/blob/aa33e47/USER_GUIDE.md) 使用。升级前请备份已有档案和申请记录。
